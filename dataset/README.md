# dataset 目录说明

本目录按“成果数据”和“验证数据”两层组织：

- `products/`：项目成果栅格及其说明、元数据
- `validation/`：验证所需的共享边界、统计真值和参考数据

当前结构如下：

- `products/demand/`：全球通信需求成果栅格、说明文档和元数据
- `products/spectrum/`：频谱相关辅助栅格和说明
- `validation/boundaries/`：共享边界数据
- `validation/truth/china_province/`：中国省级验证真值
- `validation/truth/country_level/`：国家级验证真值
